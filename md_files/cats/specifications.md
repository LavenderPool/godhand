# 📊 Бизнес-Коты (Business Cats) — Спецификации и Математика

Этот документ содержит детальные технические и математические спецификации для реализации кликера **Business Cats**, включая баланс, формулы прогрессии, дизайн интерфейса (UI/UX) и структуру данных.

## 🧮 Математика кликера и Формулы баланса

Для обеспечения долгосрочной вовлеченности игрока используется экспоненциальный рост стоимости предприятий и апгрейдов, сбалансированный степенным ростом доходов.

### 1. Формула стоимости покупки и улучшения бизнеса
Стоимость покупки следующего уровня предприятия $C_n$ рассчитывается по формуле:

$$C_n = C_0 \times M^{n-1}$$

Где:
* $C_n$ — стоимость покупки уровня $n$.
* $C_0$ — базовая стоимость 1-го уровня предприятия.
* $M$ — множитель стоимости (коэффициент инфляции). Для кошачьих бизнесов он варьируется от $1.07$ до $1.15$ в зависимости от престижности бизнеса.
* $n$ — текущий уровень предприятия (начиная с 1).

### 2. Формула пассивного дохода предприятия
Пассивный доход в секунду ($S_n$) от предприятия уровня $n$ рассчитывается по формуле:

$$S_n = S_0 \times n \times \prod (1 + B_{upgrade}) \times (1 + P_{prestige})$$

Где:
* $S_0$ — базовый доход предприятия на 1-м уровне.
* $B_{upgrade}$ — бонусы от купленных технологических апгрейдов (например, +100% к доходу лимонадного ларька).
* $P_{prestige}$ — общий бонус престижа от Золотых Рыбок (каждая Золотая Рыбка дает +2% к общему доходу).

### 3. Формула силы клика
Сила одного клика по главному котику ($Click_{power}$) зависит от текущего пассивного дохода игрока ($S_{total}$) и уровня ручных улучшений:

$$Click_{power} = (Click_{base} + 0.05 \times S_{total}) \times M_{click\_boost}$$

Где:
* $Click_{base}$ — базовый урон/клик (начинается с 1).
* $S_{total}$ — суммарный пассивный доход игрока со всех предприятий в секунду. Это предотвращает обесценивание кликов на поздних стадиях игры.
* $M_{click\_boost}$ — активные множители бустов (например, $\times 3$ от Легкой мяты или $\times 10$ от Сверхмяты).

## ⚔️ Механика Соперничества и Саботажа (PvE)

В каждом районе шкала «Доля рынка» ($Market_{share}$) колеблется между игроком и боссом-конкурентом.

### Расчет доли рынка:
$$Market_{share} = \frac{S_{player}}{S_{player} + S_{boss}} \times 100\%$$

Где:
* $S_{player}$ — суммарный доход игрока в секунду.
* $S_{boss}$ — виртуальный доход босса, который растет со временем (босс тоже делает «инвестиции» раз в несколько минут, о чем игрока предупреждает уведомление: *«Васька Рваное Ухо открыл новую палатку! Ваша доля рынка падает!»*).

### Действия саботажа:
Игрок может тратить накопленные Рыбные баксы на временное ослабление босса:

1. **Мышиный десант (Mouse Raid)**:
   * *Стоимость*: $10 \times S_{boss}$ (динамическая цена).
   * *Эффект*: Снижает $S_{boss}$ на 40% на 3 минуты.
   * *Перезарядка*: 10 минут.

2. **Валерьяновый подкуп (Valerian Bribe)**:
   * *Стоимость*: $50 \times S_{boss}$.
   * *Эффект*: Замораживает рост дохода босса на 10 минут.
   * *Перезарядка*: 20 минут.

3. **Бизнес-Дуэль (Поглощение)**:
   * Доступно при $Market_{share} \ge 75\%$.
   * Запускает мини-игру на 20 секунд, где нужно кликать по экрану быстрее босса. При победе босс капитулирует, его бизнес полностью переходит к игроку, а сам босс становится уникальным менеджером, дающим $+15\%$ к пассивной прибыли всего района.

## 📱 Дизайн интерфейса (UI/UX)

Интерфейс игры разделен на три ключевые зоны для удобства игры одной рукой (Mobile-first дизайн):

```
+---------------------------------------------------+
| [Профиль]  Жизни: 9/9   Рыбные Баксы: 1,240,500   |
| [Район] Коробково (Доля рынка: 64% [||||||...])   |
+---------------------------------------------------+
|                                                   |
|                   /\_/\                           |
|                  ( o.o )  <-- Главный Котик       |
|                   > ^ <       (Кликни меня!)      |
|                                                   |
|      [ Буст: Мята 15с ]     [ Буст: Коробка ]     |
+---------------------------------------------------+
| СПИСОК БИЗНЕСОВ:                                  |
| 1. Лимонадный ларек (Lvl 42)  [ Upgrade: $450 ]   |
| 2. Рыбный самокат   (Lvl 12)  [ Upgrade: $1,200 ] |
| 3. Мышиная мастерская (Lvl 1) [ Upgrade: $1,100 ] |
+---------------------------------------------------+
| [Бизнес]  |  [Саботаж/Босс]  |  [Сансара]  | [Магазин]|
+---------------------------------------------------+
```

### Элементы управления и вкладки:
1. **Шапка (Header)**: Отображает баланс игрока, количество оставшихся кошачьих жизней (уровень престижа) и шкалу доминирования в текущем районе.
2. **Игровая зона (Center)**: Анимированный главный котик. При клике из-под лапок вылетают монетки или рыбки. Здесь же отображаются активные бусты (таймеры кошачьей мяты).
3. **Список предприятий (Scrollable List)**: Вертикальный список всех доступных бизнесов с кнопками быстрой покупки уровней (x1, x10, x100, Max).
4. **Нижняя навигация (Footer)**:
   * **Бизнес**: Основной экран с предприятиями.
   * **Саботаж**: Экран борьбы с боссом района, покупка пакостей и запуск дуэлей.
   * **Сансара**: Экран перерождения, древо постоянных генетических улучшений за Золотые Рыбки.
   * **Магазин**: Покупка косметических предметов для котика (очки, шляпы, золотые цепи) и премиальной Сверхмяты.
