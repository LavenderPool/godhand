# 📋 Техническое задание (ТЗ): Инкрементальный кликер «Бизнес-Коты» (Business Cats)
## Платформа разработки: Godot Engine (клиентская часть с заделом под бэкенд)
## Визуальный стиль: 2D Pixel Art (ретро-стиль)

Этот документ представляет собой пошаговое руководство (Step-by-Step / System Breakdown Structure) для разработчика. Каждая система описана изолированно, с указанием архитектуры Godot (сцены, ноды, скрипты), логики данных и связей с другими системами.

## 🛠️ Архитектурные принципы в Godot

Для обеспечения масштабируемости и последующей синхронизации с бэкендом, архитектура строится на разделении данных (Model), логики (Controller) и отображения (View):

1. **Синглтоны (Autoload)**:
   - `GameManager`: Хранит глобальное состояние игрока, методы начисления валюты, вычисления силы клика, а также отвечает за сохранение/загрузку.
   - `Database`: Хранит статические данные (константы предприятий, формулы, уровни престижа, данные боссов).
   - `SignalBus`: Глобальная шина сигналов для разгрузки связей между сценами (например, `signal fish_bucks_changed(new_amount)`).

2. **Ресурсы (Custom Resources - `Resource`)**:
   - `BusinessData`: Кастомный ресурс для описания конкретного бизнеса (уровень, автоматизация, ID).
   - `PrestigeUpgradeData`: Ресурс для улучшений Сансары.

3. **Сцены и UI**:
   - Каждое окно/вкладка — это отдельная сцена, наследуемая от `Control`.
   - Обновление интерфейса происходит строго по сигналам из `SignalBus` или `GameManager`, а не в `_process(delta)`.

## 🚀 Пошаговая декомпозиция разработки (System Breakdown Structure)

### Шаг 1: Глобальное состояние, Экономика и Сохранения

#### 1.1. Класс `GameManager` (Autoload: `res://scripts/global/game_manager.gd`)
Хранит и изменяет состояние игрока.
* **Переменные состояния**:
  * `player_name: String`
  * `lives_remaining: int` (дефолт: 9)
  * `current_stage: int` (дефолт: 1)
  * `fish_bucks: float` (дефолт: 0.0)
  * `golden_fish_total: int` (дефолт: 0)
  * `golden_fish_spent: int` (дефолт: 0)
  * `businesses_state: Dictionary` (хранит `{ "business_id": { "level": int, "is_automated": bool } }`)
  * `prestige_upgrades: Dictionary` (хранит `{ "upgrade_id": level_int }`)
  * `boss_market_share: float` (дефолт: 50.0)
  * `stats_total_clicks: int`
  * `stats_total_earned: float`
  * `stats_playtime: float`
* **Ключевые методы**:
  * `add_fish_bucks(amount: float) -> void`: Начисляет валюту, вызывает сигнал `SignalBus.fish_bucks_changed`.
  * `spend_fish_bucks(amount: float) -> bool`: Проверяет баланс, вычитает, возвращает `true` при успехе.
  * `get_click_power() -> float`: Рассчитывает силу клика по формуле:
    $$\text{Click\_power} = (\text{Click\_base} + 0.05 \times S_{\text{total}}) \times M_{\text{click\_boost}}$$
    *Где $S_{\text{total}}$ — текущий суммарный пассивный доход в секунду, $M_{\text{click\_boost}}$ — активный множитель от бустов.*
  * `get_total_passive_income() -> float`: Считает сумму доходов всех купленных предприятий.

#### 1.2. Система сохранений (`res://scripts/global/save_system.gd`)
* **Метод `save_game()`**: Сериализует переменные из `GameManager` в JSON-словарь и записывает в зашифрованный файл `user://savegame.bin` (или `user://savegame.json` для дебага).
* **Метод `load_game()`**: Проверяет наличие файла. Если файл существует, парсит JSON, валидирует структуру данных (сравнивает с дефолтной схемой) и заполняет поля `GameManager`.
* **Автосохранение**: Таймер в `GameManager` вызывает `save_game()` каждые 30 секунд. Также сохранение вызывается при выходе из игры (`NOTIFICATION_WM_CLOSE_REQUEST`).

### Шаг 2: Главный кликер и Анимация Котика

#### 2.1. Сцена Главного Котика (`res://scenes/main_cat/main_cat.tscn`)
* **Структура нод**:
  * `TextureButton` (или `Area2D` + `AnimatedSprite2D` для точного клика по пикселям).
  * `AnimationPlayer`: Содержит анимации:
    * `idle`: Легкое покачивание/дыхание котика.
    * `click`: Котик быстро сжимается и разжимается (squash and stretch), лапка делает движение «цап».
    * `catnip_active`: Быстрое безумное покачивание, глаза расширены.
  * `Marker2D` (`SpawnPoint`): Точка, из которой вылетают цифры урона/монетки.

#### 2.2. Логика клика
* При нажатии на `TextureButton`:
  1. Рассчитывается `Click_power` через `GameManager`.
  2. Вызывается `GameManager.add_fish_bucks(power)`.
  3. Проигрывается анимация `click`.
  4. Спавнится сцена `FloatingText` (всплывающие цифры дохода, например, "+150 🐟").
  5. Увеличивается счетчик `stats_total_clicks`.

#### 2.3. Всплывающий текст (`res://scenes/effects/floating_text.tscn`)
* Нода `Label` (или `Label3D` в 2D-режиме, либо просто `Control` с кастомным шрифтом).
* Скрипт при спавне инициализирует текст (например, "+15$") и запускает `Tween`:
  * Перемещение вверх на 50-80 пикселей.
  * Плавное исчезновение (альфа-канал от 1.0 до 0.0).
  * Небольшое случайное отклонение по оси X (влево-вправо на 10-15 пикселей) для естественности.
  * По завершении `Tween` вызывает `queue_free()`.

### Шаг 3: Предприятия и Автоматизация (Idle-доход)

#### 3.1. Сцена Списка Предприятий (`res://scenes/business/business_list.tscn`)
* Контейнер `VBoxContainer` внутри `ScrollContainer`.
* Динамически наполняется экземплярами сцены `BusinessRow` на основе данных из `Database`.

#### 3.2. Компонент Бизнеса (`res://scenes/business/business_row.tscn`)
* **Интерфейс**:
  * Иконка бизнеса (Pixel Art).
  * Название бизнеса и текущий уровень (`Lvl 42`).
  * Прогресс-бар заполнения цикла дохода (для неавтоматизированных — заполняется при ручном запуске, для автоматизированных — крутится циклически).
  * Текст текущего дохода (`+1.2k / сек`).
  * Кнопка покупки уровня с динамической ценой.
  * Кнопка покупки автоматизации (Менеджера).
* **Логика расчета стоимости покупки**:
  $$C_n = C_0 \times M^{n-1}$$
  *Где $C_0$ — базовая цена, $M$ — инфляция бизнеса, $n$ — текущий уровень.*
* **Логика расчета дохода**:
  $$S_n = S_0 \times n \times \prod (1 + B_{\text{upgrade}}) \times (1 + P_{\text{prestige}})$$
  *Каждые 25, 50, 100, 250, 500 уровней применяется скрытый буст: $S_n = S_n \times 2$.*
* **Автоматизация**:
  * Если `is_automated == false`, игрок должен кликнуть по строке бизнеса, чтобы запустить таймер генерации дохода. Прогресс-бар заполняется, в конце начисляются деньги.
  * Если `is_automated == true`, запускается бесконечный цикл. Каждую секунду (или каждые $T$ секунд в зависимости от скорости бизнеса) начисляется доход.

### Шаг 4: Система Бустов и Уюта

#### 4.1. Легкая мята (Catnip Lite) и Сверхмята (Hyper-Catnip)
* **Логика работы**:
  * При активации в `GameManager` выставляется флаг `is_catnip_active = true` и запускается `SceneTreeTimer`.
  * Множитель `M_click_boost` увеличивается (в 3 раза для легкой, в 10 раз для сверхмяты).
  * Доход предприятий ускоряется (через уменьшение времени таймеров или умножение тиков дохода).
  * Для Сверхмяты запускается автокликер: каждую секунду генерируется 20 виртуальных кликов.
* **Визуализация**:
  * На экран накладывается шейдер (`ColorRect` во весь экран с материалом `ShaderMaterial`).
  * Шейдер искажает экран (эффект волны) и меняет палитру на кислотно-зеленую или радужную.
  * Главный котик переходит в анимацию `catnip_active`.

#### 4.2. Картонная коробка (The Box) — Оффлайн-доход
* При запуске игры рассчитывается время отсутствия:
  $$\Delta t = \text{current\_time} - \text{last\_save\_time}$$
* Базовый оффлайн-доход равен $50\%$ от реального пассивного дохода за время отсутствия.
* Уровень Коробки (покупается во вкладке улучшений) увеличивает этот процент:
  $$\text{Offline\_efficiency} = 0.50 + 0.10 \times \text{box\_level} \quad (\text{макс } 100\%)$$
* При входе игроку показывается красивое Pixel Art всплывающее окно: *«Ваш котик сладко спал в коробке уровня %d и заработал %s Рыбных баксов!»*.

#### 4.3. Золотая лазерная указка (Golden Laser)
* Рандомайзер в `GameManager` раз в 3-5 минут запускает событие.
* Сцена `LaserDot` спавнится в случайном месте экрана.
* Нода `Sprite2D` (красная светящаяся точка) двигается по случайной траектории с помощью `Tween` в течение 7 секунд.
* Если игрок успевает кликнуть по ней:
  * Проигрывается эффект взрыва искр (GPUParticles2D).
  * Игрок получает мгновенный бонус: $15 \text{ минут} \times S_{\text{total}}$.
  * Точка исчезает.

### Шаг 5: Противостояние с Боссом (PvE и Саботаж)

#### 5.1. Расчет доли рынка
* В синглтоне `GameManager` в `_process(delta)` или по таймеру (раз в секунду) пересчитывается доля рынка:
  $$\text{Market\_share} = \frac{S_{\text{player}}}{S_{\text{player}} + S_{\text{boss}}} \times 100\%$$
* Доход босса $S_{\text{boss}}$ — это виртуальная величина. Каждые 3 минуты босс делает «инвестицию», увеличивая свой доход на $15-25\%$. При этом выводится всплывающее уведомление.

#### 5.2. Панель Саботажа (`res://scenes/sabotage/sabotage_panel.tscn`)
Игрок может применить три действия (кнопки с таймерами перезарядки):
1. **Мышиный десант**:
   * Снижает $S_{\text{boss}}$ на 40% на 180 секунд.
   * Стоимость покупки: $10 \times S_{\text{boss}}$.
   * Запускает таймер обратного отсчета (Cooldown) на 10 минут.
2. **Валерьяновый подкуп**:
   * Замораживает рост $S_{\text{boss}}$ на 600 секунд (босс не делает инвестиции).
   * Стоимость покупки: $50 \times S_{\text{boss}}$.
   * Cooldown: 20 минут.
3. **Бизнес-Дуэль (Поглощение)**:
   * Кнопка активна только при $\text{Market\_share} \ge 75\%$.
   * При нажатии загружается сцена `res://scenes/duel/duel_arena.tscn`.

#### 5.3. Мини-игра «Бизнес-Дуэль»
* Экран делится на две половины. Слева — ваш котик, справа — босс района в пиксельной боевой стойке.
* По центру шкала перетягивания каната (Value от 0 до 100, дефолт 50).
* Длительность дуэли: 20 секунд.
* Игрок должен очень быстро кликать по своей половине экрана. Каждый клик сдвигает ползунок шкалы в сторону игрока на $+1.5\%$.
* Босс (ИИ) сдвигает ползунок в свою сторону на $X\%$ каждые $0.1$ секунды (сложность $X$ зависит от номера района).
* **Исход**:
  * **Победа** (ползунок на стороне игрока $> 50\%$ по истечении времени): Босс повержен. Текущий район считается пройденным. Босс переходит в статус менеджера района ($+15\%$ к доходу). Открывается доступ к следующему району.
  * **Поражение**: Игрок теряет 1 кошачью жизнь. Шкала рынка сбрасывается до 50%.

### Шаг 6: Система Престижа «Кошачья Сансара»

#### 6.1. Логика Сброса
* Доступно, если игрок накопил достаточное количество денег за все время (рассчитывается количество Золотых Рыбок к получению):
  $$\text{Golden\_Fish\_To\_Earn} = 150 \times \sqrt{\frac{\text{Total\_Earned}}{10^6}} - \text{Golden\_Fish\_Total\_Previously\_Earned}$$
* При подтверждении сброса:
  1. `GameManager.lives_remaining` уменьшается на 1 (или сбрасывается, если это лорный престиж перехода на новый цикл жизней).
  2. Все предприятия сбрасываются на уровень 0, автоматизация отключается.
  3. Текущий баланс Рыбных баксов сбрасывается в 0.
  4. Начисляются заработанные Золотые Рыбки.
  5. Игра начинается с 1-го района (или сохраняется открытый максимальный район, в зависимости от настроек баланса).

#### 6.2. Древо генетических улучшений (`res://scenes/samsara/samsara_tree.tscn`)
Экран с покупкой постоянных пассивных баффов за Золотые Рыбки:
* **Генетическая память**: $+100\%$ к силе клика за уровень.
* **Ароматный сорт**: $+10\%$ к длительности мяты за уровень.
* **Золотая коробка**: $+10\%$ к эффективности оффлайн-дохода за уровень.
* **Корпоративный шпионаж**: $-15\%$ к стоимости саботажа за уровень.

## 🎨 Спецификации для Pixel Art и Аудио

### Графические ассеты (Размерность и Сетка)
* **Разрешение проекта**: $720 \times 1280$ (вертикальный мобильный формат, Mobile-first).
* **Сетка Pixel Art**: Базовый размер тайлов и иконок — $16 \times 16$ или $32 \times 32$ пикселей, масштабируемый без сглаживания (`Texture Filter: Nearest` в настройках Godot).
* **Палитра**: Рекомендуется использовать ограниченную ретро-палитру (например, *NES Classic* или *GB Color* расширенную) для сохранения стилистики.

### Звуковое оформление (SFX & Music)
* **Музыка**:
  * Обычное состояние: Расслабленный Lo-Fi Chiptune.
  * Состояние Мяты: Ускоренный, динамичный Hardbass Chiptune или Synthwave.
* **Звуковые эффекты**:
  * Клик по котику: Мягкое "мяу" (разные тональности), хруст монетки, "царап".
  * Покупка апгрейда: Звон кассового аппарата (8-bit).
  * Активация саботажа: Звук писка мышей или сирены.
  * Победа в дуэли: Триумфальное фанфарное мяуканье.
