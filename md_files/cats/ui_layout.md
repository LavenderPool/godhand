# 🎨 Текстовый дизайн интерфейсов (UI/UX Layouts) — «Бизнес-Коты»

Этот документ содержит текстовые и ASCII-макеты всех основных экранов игры в вертикальном мобильном разрешении (целевое соотношение сторон **9:16**, базовое разрешение **720x1280**). 

Все элементы адаптированы под **Pixel Art** стилистику с использованием моноширинных рамок, индикаторов и кнопок.

---

## 📱 Общая структура экрана (Мастер-шаблон)

Каждый экран состоит из трех фиксированных зон:
1. **Header (Шапка)**: Статичная зона с балансом, жизнями и текущим прогрессом района.
2. **Content Area (Игровая/Вкладочная зона)**: Динамическая зона, которая меняется при переключении вкладок в футере.
3. **Footer (Нижняя навигация)**: Фиксированная панель переключения вкладок.

---

## 🏠 Вкладка 1: «Бизнес» (Основной игровой экран)

Здесь игрок кликает по главному котику и управляет своими предприятиями.

```
+---------------------------------------------------+
| [🐱 CatBoss]     ❤️ Жизни: 9/9     🐟 1,240,500.00 |
| [🏙️ Район 1] Коробково (Доля рынка: 64%)          |
| [||||||||||||||||||||||||||||||.......] [⚔️ ДУЭЛЬ] |
+---------------------------------------------------+
|                                                   |
|                      /\_/\                        |
|                     ( o.o )                       |
|                      > ^ <                        |
|                                                   |
|                 [ Главный Котик ]                 |
|               (Кликни для прибыли!)               |
|                                                   |
|   +--------------------+    +-----------------+   |
|   | 🌿 Легкая Мята     |    | 📦 Коробка Lvl.3|   |
|   | [ 00:15 ] (Активна)|    | Оффлайн: +80%   |   |
|   +--------------------+    +-----------------+   |
+---------------------------------------------------+
| СПИСОК БИЗНЕСОВ:                 [ Множитель: x1 ]|
|                                                   |
| 1. [🍋] Лимонадный ларек (Lvl 42)                 |
|    [||||||||||||||||||||||||||||||||||] +1.2k/сек |
|    [ Улучшить: 450 🐟 ]      [ АВТО: КУПЛЕНО ]    |
|                                                   |
| 2. [🛵] Рыбный самокат (Lvl 12)                   |
|    [||||||||||||......................] +120/сек  |
|    [ Улучшить: 1,200 🐟 ]    [ АВТО: КУПЛЕНО ]    |
|                                                   |
| 3. [🐭] Мышиная мастерская (Lvl 1)                |
|    [..................................] +8/сек    |
|    [ Улучшить: 1,100 🐟 ]    [ Нанять: 5,000 🐟 ] |
+---------------------------------------------------+
| [💼 БИЗНЕС] | [🐭 САБОТАЖ] | [🌀 САНСАРА] | [🛒 ШОП] |
+---------------------------------------------------+
```

### Пояснения к элементам:
* **Шкала доли рынка**: Визуальный прогресс-бар. Если доля игрока $\ge 75\%$, кнопка `[⚔️ ДУЭЛЬ]` начинает мигать неоновым светом, приглашая к битве за район.
* **Главный Котик**: В зависимости от баланса спрайт котика меняется (оборванный кот -> кот в ошейнике -> кот в галстуке -> кот в цилиндре с моноклем). При клике из-под лапок вылетают пиксельные монетки.
* **Множитель покупки**: Кнопка `[ Множитель: x1 ]` в правом верхнем углу списка бизнесов переключает режим покупки уровней: `x1` -> `x10` -> `x100` -> `MAX`.
* **Прогресс-бар бизнеса**: Показывает цикл генерации дохода. Для автоматизированных бизнесов он заполняется циклически сам. Для неавтоматизированных — заполняется только при клике на саму строку бизнеса.

## ⚔️ Экран «Бизнес-Дуэль» (Мини-игра)

Отдельный полноэкранный режим, запускающийся при попытке поглотить босса района.

```
+---------------------------------------------------+
|                  БИЗНЕС-ДУЭЛЬ!                    |
|              Осталось времени: 14с                |
+---------------------------------------------------+
|                                                   |
|     ИГРОК (Вы)                      БОСС (Васька) |
|       /\_/\                             /\_/\     |
|      ( >.< )                           ( >д< )    |
|      >  ^  <                           >  ^  <    |
|                                                   |
+---------------------------------------------------+
|                                                   |
|                 ШКАЛА ВЛИЯНИЯ                     |
|                                                   |
| Игрок: 58%                      Босс: 42%         |
| [===================|===============]             |
|                     ^                             |
|                  Центр                            |
|                                                   |
+---------------------------------------------------+
|                                                   |
|                                                   |
|                 [ КЛИКАЙ СЮДА! ]                  |
|             ЖМИ КАК МОЖНО БЫСТРЕЕ!                |
|                                                   |
|                                                   |
+---------------------------------------------------+
|              ПОБЕДИТЕ, ЧТОБЫ ЗАБРАТЬ РАЙОН!       |
+---------------------------------------------------+
```

### Пояснения к элементам:
* **Шкала влияния (Перетягивание каната)**: Ползунок `^` двигается влево-вправо в реальном времени. Если игрок кликает по кнопке `[ КЛИКАЙ СЮДА! ]`, ползунок сдвигается влево (в сторону игрока). Босс автоматически сдвигает его вправо с частотой, зависящей от сложности.
* **Таймер**: Показывает обратный отсчет от 20 секунд. Если по истечении времени ползунок находится на стороне игрока (доля $> 50\%$), присуждается победа.
